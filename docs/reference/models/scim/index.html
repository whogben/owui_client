    scim

    SCIM 2.0 models for the Open WebUI API.

    Models that mirror the backend's SCIM (System for Cross-domain Identity Management) schemas and request/response payloads. These are used by the experimental SCIM 2.0 endpoints for user and group provisioning.

    Classes

    SCIMError

    Bases: BaseModel

    SCIM-compliant error response.

    Returned when a SCIM operation fails. The scimType field provides a machine-readable error category per RFC 7644.

    Attributes

    schemas 
    schemas: list[str] = [SCIM_ERROR_SCHEMA]

    Schema URIs defining this error response. Always includes the SCIM error schema.

    status 
    status: str

    HTTP status code as a string (e.g. '404', '409').

    scimType 
    scimType: Optional[str] = None

    SCIM-specific error type.

    Common values: - invalidValue: The request body or parameter is malformed or invalid. - uniqueness: A resource with the same unique attribute already exists. - invalidSyntax: The filter or query syntax is invalid.

    detail 
    detail: Optional[str] = None

    Human-readable description of the error.

    SCIMUser

    Bases: BaseModel

    SCIM User resource representation.

    Maps internal Open WebUI user records to the SCIM 2.0 User schema. The userName field is typically the user's email address.

    Returned by:
    • Code Reference routers scim Classes SCIMClient Functions
      • create_user
      • get_user
      • patch_user
      • update_user

    Attributes

    schemas 
    schemas: list[str] = [SCIM_USER_SCHEMA]

    Schema URIs defining this resource.

    id 
    id: str

    Unique identifier for the user within Open WebUI.

    externalId 
    externalId: Optional[str] = None

    External identifier assigned by the identity provider for account linking.

    userName 
    userName: str

    User identifier, typically the email address.

    name 
    name: Optional[SCIMName] = None

    Structured name components (givenName, familyName, etc.).

    displayName 
    displayName: str

    Human-readable display name for the user.

    emails 
    emails: list[SCIMEmail]

    List of email addresses associated with the user.

    active 
    active: bool = True

    Whether the user account is active.

    In Open WebUI, inactive users have role 'pending'.

    photos 
    photos: Optional[list[SCIMPhoto]] = None

    List of photo references for the user.

    groups 
    groups: Optional[list[dict[str, str]]] = None

    Groups the user is a member of.

    Dict Fields
    • value (str): Group ID
    • display (str): Group display name
    • $ref (str): SCIM resource URI for the group
    • type (str): Membership type, typically 'direct'
    meta 
    meta: SCIMMeta

    Resource metadata including creation time and location.

    SCIMPatchOperation

    Bases: BaseModel

    Single operation within a SCIM Patch request.

    Supports add, replace, and remove operations on resource attributes. The path field uses attribute notation (e.g. 'displayName', 'members', 'emails[primary eq true].value').

    Returned by:
    • Code Reference models scim Classes SCIMPatchRequest Attributes Operations

    Attributes

    op 
    op: str

    Operation type: 'add', 'replace', or 'remove'.

    path 
    path: Optional[str] = None

    Target attribute path for the operation.

    Examples: - displayName - members - emails[primary eq true].value - name.formatted

    value 
    value: Optional[Any] = None

    Value to apply for add or replace operations.

    For remove operations, this is typically omitted. For members, this may be a list of dicts with value keys.
